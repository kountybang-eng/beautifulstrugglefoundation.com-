  # Beautiful Struggle Inc. (`beautifulstrugglefoundation.com`)

Welcome to the official repository for **Beautiful Struggle Inc.** Our platform is built to support low-income families and individuals navigating hardship by removing one of the largest obstacles to stability: reliable, affordable transportation.

---

## 🌟 Our Mission

At **Beautiful Struggle Inc.**, we turn life's hardest challenges into strength, resilience, and purpose. As a family-run nonprofit built on shared lived experiences, we focus on empowering individuals and families by providing affordable vehicles, donating up to half the vehicle value, and removing transportation barriers so people can get back on the road to independence.

 Hardship doesn't define you—it refines you.

---

## 🚀 Key Initiatives & Features

- **Affordable Transportation:** Sourcing, restoring, and facilitating affordable vehicle placement for low-income families in need.
- **Vehicle Scout Tracker:** Integrating web and app tools (including our SCOUTERS app) to source, track, and manage vehicle acquisitions and community donations.
- **Community Empowerment:** Connecting families with practical guidance, mentorship, and local support resources to build a stable future.

---

## 🎨 Design & Tech Stack

- **Frontend:** Modern HTML5 / CSS / JavaScript (Dark Mode UI with Husky Purple and Bright Green accents)
- **Backend & Database:** Supabase (Auth, Vehicle Tracker Data)
- **Hosting & DNS:** GitHub Pages & Cloudflare (`beautifulstrugglefoundation.com`)
- **Version Control:** Git & GitHub

## 🛠️ Extended Description

Transportation isn't a luxury—it's a critical bridge to employment, healthcare, childcare, and basic stability. **Beautiful Struggle Inc.** was founded on the belief that a single setback shouldn't derail a family's future. By pairing real-world mechanical and resource solutions with community advocacy, we help individuals overcome everyday obstacles and build a lasting legacy.

### Core Values
* **Resilience:** Transforming lived hardship into personal strength and community support.
* **Access:** Breaking down systemic and financial barriers to reliable transportation.
* **Integrity & Family:** Operating with transparent, hands-on, community-first values.
